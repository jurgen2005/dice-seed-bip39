# Dice seed (BIP39)

A single, self-contained HTML page that turns **physical dice rolls** into a BIP39 seed phrase (12 or 24 words), fully offline, and lets you **verify** the result instead of trusting it.

[Nederlandse versie](README.nl.md)

> **Status: unaudited.** The cryptography in this page (SHA-256, SHA-512, PBKDF2, RIPEMD-160, secp256k1, BIP32, QR encoding) is implemented in plain JavaScript and tested against official test vectors and independent libraries, but it has **not** been reviewed by an independent security auditor. Always cross-check the result in a second, independent tool before you put real value on a seed. No warranty, see [LICENSE](LICENSE).

## Try it online (trial version)

**[Open the online trial version](https://jurgen2005.github.io/dice-seed-bip39/dist/dice-seed.html)**

The online version is for looking around and trying the tool, not for making a real seed. It is the same file as `dist/dice-seed.html` in this repository. The page detects that it was opened from a web address instead of as a file on your own computer, and then switches to trial mode:

- a red banner "ONLINE TRIAL VERSION" at the top, and "online trial version" in the tab title;
- every result is marked **TESTSEED**, also when you enter real dice rolls or cards, and also an existing seed you type in;
- a fixed warning at "Enter existing seed" never to type a real seed there.

The calculations are the same as in the downloaded file: the same rolls give the same words. So you can use the online version to learn the steps and to practise recomputing in Ian Coleman's tool.

What this means for you:

- **Never use a seed from the online version for real value**, not even if you rolled real dice. The page then runs on your everyday, connected computer, in your normal browser, and you have not checked which file you were served.
- **Never type an existing, real seed into the online version.** A browser extension with access to all websites (password managers, translation and writing tools often have that) can read everything on the page, including the words. In Chrome and Edge, extensions can only read local files if you explicitly allow it. If you did type a real seed: treat it as leaked and move the funds to a new seed.
- **You cannot verify what you get.** GitHub Pages serves whatever is in the `main` branch at that moment, normally the latest release. The SHA-256 check under *Verify before use* only works on a downloaded file. Whoever has access to the repository or the GitHub account (the maintainer, or someone who takes over the account) can change the online page. The trial mode protects against mistakes, not against a modified copy: such a copy can simply leave out the banner and the marking.
- **Your visit is not anonymous.** The page itself sends nothing (after loading, the Content Security Policy blocks all network access), but GitHub, like any web host, sees your IP address when you open the page.
- **Going offline after loading does not help.** The problem is not the connection during the calculation, but the unverified file and the everyday computer. That is why online the trial banner replaces the "This computer is online" warning.
- Trial mode switches on for everything that is not a local file (`file://`), including a web server on your own computer. For real use, open the downloaded and verified file directly from disk.

For real use, see *Verify before use* and *Safe use* below.

## Why

A seed generated by a device's internal random generator cannot be checked from the outside. The Coldcard incident of 2026 showed how that can go wrong for years without anyone noticing. With dice, **you** are the source of randomness, and the mapping from rolls to words is deterministic, so anyone can recompute it.

This page:

- uses **no random generator for real seeds**. The words are `SHA-256(your rolls)`, nothing else;
- uses the same convention as [Ian Coleman's BIP39 tool](https://github.com/iancoleman/bip39) (Entropy type **Base 10**) and SeedSigner's dice mode, so you can cross-check in an independent tool;
- refuses too few rolls, with a conservative minimum that holds even for a noticeably biased die.

## Features

- 12 or 24 words from dice rolls. Minimum 56 / 111 rolls (hard limit), 100 / 199 recommended. More rolls always count.
- Verification mode for SeedSigner's 50 / 99 rolls (clearly marked, only for recomputing).
- Alternative source behind a button: **playing cards**. One full shuffled deck (52 cards, 225 bit) for 12 words, two rounds with a reshuffle in between for 24 words. Visual 4 x 13 card grid (entered cards grey out with their position), keyboard shortcuts (rank, then suit) or typed text like `AS TH 9D`. Every card must appear exactly once per round; checks for remnants of a sorted deck and for too little reshuffling between rounds. The words are `SHA-256("AS TH 9D ...")`, recomputable via `shasum` and Ian Coleman (Hex, raw entropy).
- Quality checks on the rolls: chi² over the six faces, per-face deviation in σ with detectability, long runs, typed patterns.
- Master fingerprint (BIP32), with optional BIP39 passphrase (NFKD, with a warning for non-ASCII).
- **Compact SeedQR** (SeedSigner standard) with a zoomable grid, block-by-block copy mode and the official SeedSigner printable templates embedded.
- First 10 BIP-84 receive addresses with QR, plus an address checker (receive and change, up to 1000 each).
- Watch-only account key `m/84'/0'/0'`: descriptor, `[fingerprint/path]zpub`, zpub or xpub, as text and QR.
- Enter an existing seed (12/24 boxes with autocomplete) and calculate a valid last word from coin flips.
- Automatic hiding of words and QR after inactivity.
- English and Dutch (starts in the browser language, nothing is stored).
- Online trial version on GitHub Pages: the page detects that it was not opened as a local file and marks every result TESTSEED (see *Try it online*).
- Self-test on every load (NIST SHA-256, official BIP39, BIP32/BIP84/BIP-380 vectors, QR matrices). Calculation is blocked if it fails.
- Content Security Policy blocks all network access. No storage, no cookies, no external files.

## Verify before use

1. Download `dice-seed.html` from the [latest release](https://github.com/jurgen2005/dice-seed-bip39/releases/latest).
2. Check its SHA-256 against `SHA256SUMS` in the release and in this repository:
   - macOS: `shasum -a 256 dice-seed.html`
   - Linux: `sha256sum dice-seed.html`
   - Windows (PowerShell): `Get-FileHash dice-seed.html`
3. Optional, stronger: rebuild it yourself and compare (see *Reproducible build*).
4. Open the page and check that the self-test badge is green.

## Safe use (short version)

1. The downloaded and verified file, not the online trial version, on an offline computer, preferably booted from a live USB (e.g. Tails). No network.
2. A good die (casino dice are ideal). Really roll it: shake and let it roll, do not place it or redo rolls. Write the rolls on paper first.
3. Enter the rolls, calculate, and **recompute the same rolls in a second tool** (Ian Coleman, Entropy, Base 10). Same words = neither tool manipulated your input.
4. Write the words on paper or metal. No photos, screenshots or copy/paste.
5. Click "Wipe everything", close the browser, shut down the computer.

The page explains all of this in more detail under *Verifying and using safely*.

## Reproducible build

`dist/dice-seed.html` is generated from `src/` by `build.py` (Python 3, standard library only):

```sh
python3 build.py
# prints the SHA-256 of dist/dice-seed.html; it must match SHA256SUMS
```

The build checks that the embedded wordlist is the official BIP39 `english.txt` and that the embedded templates are byte-identical to SeedSigner's originals.

| Path | Content |
|---|---|
| `src/template.html` | The page source (HTML, CSS, JavaScript) with placeholders |
| `src/wordlist/english.txt` | Official BIP39 English wordlist |
| `src/templates/*.pdf` | Official SeedSigner `grid_wfingerprint` templates |
| `src/i18n_en.json` | English translations of the static Dutch text |
| `build.py` | Fills in the placeholders, writes `dist/dice-seed.html` |
| `tests/test_crosscheck.py` | Cross-check against embit and zxing-cpp in headless Chromium, plus the online trial mode over `http://` |

## Limitations

- It does not protect against a compromised computer, screen recording or someone watching. Use an offline live USB.
- The statistical checks catch typing patterns and gross bias, not subtle bias. The conservative minimum covers that.
- With playing cards the security depends on how thoroughly you shuffle (at least 7 riffles), and that cannot be seen from the result. The checks only catch gross failures.
- The "Test rolls (random)" and "Test cards (random)" buttons use the browser RNG. They exist only to try the tool and mark the result as TESTSEED. Never use them for real value.
- The online trial version is not meant for real value, see *Try it online*.
- Unaudited, see above.
